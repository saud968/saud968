## 📚 Free learning projects

### [Power BI Labs — Sales Data Quality Challenge](https://github.com/saud968/datatalkswithsaud-powerbi-labs)

A beginner-friendly, hands-on exercise using **fully synthetic data**. Practice cleaning a messy sales CSV in Power Query, handling duplicates and missing values, writing DAX measures, and reconciling results against known expected totals.

- 125 synthetic input rows, including 5 exact duplicates
- 116 reportable orders after applying the documented exercise rules
- Expected revenue: **₹3,29,570**
- Includes exercise instructions, solution notes, example DAX, and a Python data-validation script
- Designed for **Power BI Desktop**; no Power BI Service account required

**Start here:** [Beginner walkthrough](https://github.com/saud968/datatalkswithsaud-powerbi-labs/blob/main/docs/START_HERE.md) · [Try the exercise](https://github.com/saud968/datatalkswithsaud-powerbi-labs/blob/main/exercises/challenge.md) · [Explore the repository](https://github.com/saud968/datatalkswithsaud-powerbi-labs)

> This learning project does not yet include a completed or independently tested `.pbix` report.

### [SQL Labs — Free SQL Practice from Beginner to Advanced](https://github.com/saud968/datatalkswithsaud-sql-labs)

Practice **12 runnable SQL challenges** on fictional customer and order datasets, covering joins, aggregation, window functions, and data-quality checks. Every exercise has a tested SQLite solution and expected output; Python's built-in SQLite means no paid SQL software or cloud account is required.

**Start here:** [Beginner guide](https://github.com/saud968/datatalkswithsaud-sql-labs/blob/main/docs/START_HERE.md) · [Try the exercises](https://github.com/saud968/datatalkswithsaud-sql-labs/blob/main/exercises/README.md) · [View successful automated checks](https://github.com/saud968/datatalkswithsaud-sql-labs/actions)
